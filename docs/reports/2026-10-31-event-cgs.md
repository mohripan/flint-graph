# Event CGs and gallery (#161 presentation, runtime 0.5.0)

Delivered [ADR 0042](../adr/0042-event-cgs-and-gallery.md): format 2 stage nodes set,
carry or clear a full-stage `cg` image overlay, with dialogue and choices above it.
Backgrounds, character placements and expressions continue underneath. Stage views,
frames and saves carry `cg`; older saves without it restore `null`. Format 1 refuses
the field. Existing stable validation codes distinguish missing assets, font assets,
malformed IDs and format 1 fields.

The gallery lists distinct CGs in deterministic first-use order, including locked
entries on unplayed routes. Only CGs present on settled screens unlock. Unlocks live
outside save slots, persist by story ID in exports, survive Restart/Load, and remain
memory-only in Studio playtests. Gallery input is paused and focus stays in its
controls; Escape closes the gallery before closing a playtest.

The Studio stage panel picks existing story images and approved library images,
offers explicit clear/keep controls and previews the same layer order. CG references
participate in asset retention and inherited-stage analysis. Mid-scene script steps
describe CG changes. No migration, assistant or image-generation changes are included.
